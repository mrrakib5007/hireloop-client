# HireLoop

## Description
HireLoop is a modern job board and talent platform that connects job seekers with leading global employers. The platform provides intuitive job searching, streamlined application workflows, and an atmospheric dark glassmorphic user interface optimized for performance and responsiveness.

## Technology
- Framework: Next.js 16 (App Router)
- UI Library: React 19
- Language: TypeScript
- Styling: Tailwind CSS v4
- Component Primitives: Base UI (@base-ui/react)
- Authentication: Better Auth
- Database: MongoDB
- Notifications: React Hot Toast
- Icons: Lucide React

## Features
- Authentication: Email/password and Google OAuth sign-in and account registration
- User Session & Profile: Dynamic profile avatar with responsive dropdown menu and fallback handling
- Job Search: Search filtering by job title, keywords, company, and location/remote preferences
- Navigation: Sticky glassmorphic desktop navbar and responsive mobile drawer navigation
- Tiered Pricing: Flexible monthly and yearly subscription billing tiers
- Platform Capabilities: AI job matching, verified employer listings, and career growth resources
- Responsive Design: Fully responsive layouts across mobile, tablet, and desktop screens
